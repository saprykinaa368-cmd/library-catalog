# Каталог домашней библиотеки

Консольное приложение для управления домашней библиотекой. Реализует предметную область хранения книг (Комната -> Шкаф -> Полка), выдачи экземпляров и поиска.

## Модель данных
- **Book**: Неизменяемая запись (record). Ключ равенства — ISBN.
- **BookCopy**: Конкретный физический экземпляр книги с инвентарным номером и состоянием.
- **Локации**: Реализуют интерфейс `Addressable` для полиморфного получения адреса.
- **Жанры и состояния**: Реализованы через `Enum`.

## Запуск проекта
Проект собирается с помощью Maven. Для запуска консольной демонстрации из корня проекта выполните команду:
`mvn clean compile exec:java -Dexec.mainClass="ru.library.Main"`
